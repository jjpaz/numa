# Two-minute demonstration

Before presenting: use fictional experiences, check API health and cloud smoke tests, warm the voice model if connected, open the patient portal and psychologist portal in separate browser contexts, and check the exact frontend/backend origins. The local preview explicitly does not run emotional ML.

**0:00–0:20 — The idea.** Open Numa. “Some people find direct mood questions difficult. Numa offers a private space to talk about the day. It keeps vocal observations and explicit self-report separate.”

**0:20–0:55 — A private page.** Sign into the fresh patient account, add a note, accept processing consent, record a fictional day, then stop. Show the transcript and editable summary alongside the separate voice observation. If Gemini is not connected, state that clearly and type the transcript instead. Never present a typed or fictional result as live model inference.

**0:55–1:15 — Close the loop.** Save the page, try the suggested small action, choose optional helpfulness feedback. Point out the optional comparison recording and that a vocal difference alone does not prove benefit.

**1:15–1:40 — Learn over time.** Switch to the fictional sample journal in a separate context. Show the simulated context, observation counts and individual baseline. “We cannot manufacture a real personal baseline in a two-minute demo. This fictional history shows the longitudinal experience.”

**1:40–2:00 — A view with boundaries.** Open the psychologist overview. The fresh entry count and activity feedback appear. The clinician sees trends, context and a printable report, while private journal words are excluded by the API. End with possible future Apple Health and Last.fm connections, currently labelled as unconnected.

## Honest fallback

If cloud credentials are not ready, demonstrate the local written-entry flow plus real acoustic measurements. Clearly state what is and is not live. Never insert a synthetic baseline into the fresh profile, impersonate API analysis with canned emotion labels, or imply a future integration is connected.
